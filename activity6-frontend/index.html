    About this project

    Campus Maintenance Requests is a fault reporting system for students. Any student can report a problem around campus, such as a broken socket, a leaking tap, damaged furniture or a faulty appliance. Each report reaches the Campus Help Desk, which moves it from Pending to In progress to Completed, so students can see what is happening to their report.

    This version uses browser demonstration data. Reports are saved in this browser with localStorage, so they will not appear on another device or browser. The sample reports, names and student numbers are made up.
