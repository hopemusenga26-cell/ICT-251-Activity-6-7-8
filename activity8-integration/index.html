    About this project

    Campus Maintenance Requests is a web system for reporting and tracking maintenance problems around campus. Each request has a title, a category, a description and a status of Pending, In progress or Completed.

    This version is connected to a live backend. Every request you add, edit or delete is saved in the shared database, so the same records appear on any device. The sample requests are made up.

    How to use it

    1. Fill in the form under Report or update a request and choose Add request.
    2. Find requests with the title search or the status filter.
    3. Use View for full details, Edit to change a request, or Delete to remove it.

    If the list does not load at first, wait a minute: the free server may be starting up.
